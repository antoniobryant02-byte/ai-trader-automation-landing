Real internal build

From command-based options bot to automatic Telegram + Discord digest.

I converted an existing options scanner that required manual commands into a scheduled command center that checks a watchlist, formats a digest, logs the run, and delivers to Telegram and Discord.

Before

The scanner worked, but only after typing commands like:

/check AAPL call /scan /watchlist

After

The system runs automatically on weekdays and sends scheduled digests:

8:30 AM CT → Telegram 8:35 AM CT → Discord 11:30/11:35 → mid-day digest 2:30/2:35 → afternoon digest
Architecture

The wrapper pattern.

1. Existing command bot: Options Scout
2. Direct CLI runner: python3 -m option_scout check <ticker> <call|put>
3. Watchlist reader: AAPL, NVDA, TSLA calls
4. Digest wrapper: ~/.hermes/scripts/options_scout_digest.py
5. Scheduler: Hermes cron no-agent jobs
6. Delivery: Telegram + Discord #hermes-chat
7. Logs: raw output + status JSON
3

Watchlist tickers automated

AAPL, NVDA, TSLA.

6

Scheduled deliveries per trading day

Three to Telegram and three to Discord.
